# MADLauncher

My first Minecraft launcher, written in C#. Requires **.NET Framework 4.5** and **Visual Studio 2013** to compile.

## Features

Many features are implemented, but there is currently **no Forge or Fabric support**. You can help by contributing code — and more!

## Supported Windows Versions

### Non-Server
- Windows Vista SP2
- Windows 7 SP1
- Windows 8
- And newer

### Server
- Windows Server 2008 SP2
- Windows Server 2008 R2 SP1 (x64)
- Windows Server 2012
- And newer
